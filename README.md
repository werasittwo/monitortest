# 🌿 ระบบติดตามตัวชี้วัด กพร. ประจำปีงบประมาณ พ.ศ. 2570 (OPDC KPI Command Center)

เว็บแอปพลิเคชันสำหรับติดตามและประเมินผลตัวชี้วัดตามคำรับรองการปฏิบัติราชการ (กพร.) ประจำปีงบประมาณ พ.ศ. 2570 ออกแบบด้วยโทนสีเขียวธรรมชาติ (Natural Sage & Forest Green) สบายตา คมชัด เหมาะสำหรับฉายขึ้นจอโปรเจคเตอร์ในการประชุมผู้บริหาร และเชื่อมโยงฐานข้อมูลกับ **Google Sheets**

## ✨ คุณสมบัติหลัก
1. **หน้า 1: สำหรับผู้บริหาร (Executive Projector View)**
   - แสดงภาพรวมความสำเร็จเฉลี่ยถ่วงน้ำหนัก (%) และคะแนนประเมิน กพร. เฉลี่ย (เต็ม 5.00)
   - สรุปผลสัมฤทธิ์แยกตามมิติการประเมิน กพร. และการกระจายสถานะตัวชี้วัด
   - โหมดขึ้นโปรเจคเตอร์เต็มจอ (Projector Fullscreen Mode), สลับโทนสีเขียวอ่อนสบายตา / เขียวเข้มธรรมชาติ และโหมดนำเสนออัตโนมัติ (Auto-Slide)
2. **หน้า 2: สำหรับเจ้าหน้าที่ (Staff Management Portal)**
   - บันทึกและแก้ไขตัวเลขผลงานจริงในตารางได้ทันที (Quick Inline Edit)
   - เพิ่ม / แก้ไข / ลบ รายการตัวชี้วัด (CRUD)
   - อัปโหลดไฟล์ CSV เพื่อนำเข้าข้อมูลทั้งตาราง และส่งออกข้อมูลเป็นไฟล์ CSV
   - อัปโหลดไฟล์เอกสารหลักฐานแนบรายตัวชี้วัดเข้าสู่ Google Drive อัตโนมัติ

## 🗂️ โครงสร้างไฟล์ในโปรเจกต์
- `index.html` — หน้าเว็บแอปพลิเคชันหลัก
- `styles.css` — สไตล์ชีตโทนสีเขียวธรรมชาติและโหมดโปรเจคเตอร์
- `app.js` — ระบบคำนวณคะแนน กพร. 5 ระดับ และการเชื่อมต่อ Google Sheets
- `google-apps-script/Code.gs` — โค้ดสำหรับติดตั้งใน Google Apps Script เพื่อเขียนข้อมูลกลับลง Google Sheets
- `KPI_2570_Template.csv` — ไฟล์แม่แบบข้อมูลตัวชี้วัด กพร. ปี 2570
